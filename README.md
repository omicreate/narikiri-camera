# なりきりカメラ(仮称)

スマホのカメラにうつると、きょうりゅう・どうぶつ・のりもの・おしごとに へんしんできる、親子向けの ARカメラ(Webアプリ)。
インストール不要。映像は端末の中だけで処理し、どこにも送らない。

## できること

| 区分 | なりきり | 口をあける/画面タッチで起きること |
|---|---|---|
| きょうりゅう | ティラノ / トリケラ / くびなが(に乗る) | 火をふく / ドッシーン / 首長竜が鳴く |
| どうぶつ | ライオン / うさぎ / パンダ | ガオー / 耳がはねる・にんじん / 竹を食べる |
| のりもの | しょうぼうしゃ / きかんしゃ / ロケット | サイレンと放水 / 汽笛と蒸気 / 発射 |
| おしごと | しょうぼうし / コックさん / うちゅうひこうし | 放水とにじ / ごちそうが口へ / 星がまう |

- 2人以上うつっても、それぞれに着せる(最大4人)。きかんしゃは 右の人が機関車、ほかは客車。
- 「はいけい」ボタンで 背景を その世界に変える/カメラそのままを 切りかえ。
- 「まねっこ」: カメレオンのレオンと同じ顔を5つ。できた顔を1枚の記念コラージュにする。
- 写真は「ほぞん」を押したときだけ 端末に保存する。「しゃしんで あそぶ」で アルバムの写真にも着せられる。

## しくみ

```
カメラ/写真 ─→ 顔の追跡(MediaPipe・最大4人) ─→ なりきりの動き(口・笑顔・顔の向き) ─┐
        └─→ 人物の切り抜き(背景を変えるときだけ) ──────────────────────────┤
                                                                                      ↓
        背景の世界 → 人物 → 服 → フード → 手前の絵 → 粒(火・水・星) の順に重ねて描く
```

- 背景を変えているときは、なりきりが画面からはみ出さないよう 人物の大きさと位置を自動で合わせる(`engine.js` の `_frame`)。
- 重い端末では、切り抜きの回数 → 画面の細かさ の順に下げて 動きを守る(`engine.js` の `_adapt`)。
- GPU で動かない端末は CPU に切りかえる(`tracker.js` / `main.js`)。

## フォルダ

```
index.html / style.css      画面
src/main.js                 操作と全体の流れ
src/engine.js               毎コマの処理と重ね描き、構図の自動合わせ
src/tracker.js              顔の追跡・人物の切り抜き
src/items_*.js              なりきりの定義(絵と動き)   ← 増やすのはここ
src/worlds.js               背景の世界
src/art.js / draw.js        絵の共通部品、重ねる順番、一覧用の小さな絵
src/fx.js / audio.js        粒の演出 / 効果音(すべて合成。音声ファイルなし)
src/game.js / guide.js      まねっこゲーム / おてほん役レオン
src/capture.js              写真の仕上げ・保存・共有・コラージュ
vendor/mediapipe/           顔認識ライブラリ(@mediapipe/tasks-vision 1.1.1)
models/                     顔・切り抜きのモデル
tools/                      開発用(試験台・アイコン作成)。公開には不要
```

## 手順書: なりきりを1つ増やす

- 目的: 新しい なりきりを 一覧に足す。
- 入力: 名前、区分、背景の世界、口をあけたときの かけ声と動き。
- 手順:
  1. `src/items_<区分>.js` に定義を1つ足し、末尾の `export default [...]` に並べる。
  2. 絵は「顔の幅 = 1」「顔の中心 = (0,0)」「下が +y」の単位で描く。`hood`(顔の穴あき)・`front`(手前)・`wear`(服)・`back`(人物のうしろ)から必要なものだけ書く。
  3. `ext`(左右上下に どこまで はみ出すか)と `thumb`(一覧の絵の大きさ)を入れる。
  4. `tools/gallery.html` を開いて 見本の顔で形を確かめる。
- 完了条件: 一覧に出る / 1人と2人の場面で はみ出さない / 口をあけると かけ声と動きが出る / コンソールにエラーがない。
- 失敗時: 絵がずれる → `ext` と座標の単位を見直す。顔が隠れる → 顔にかかる部品は `hood` に入れる(顔の形に 穴があく)。

## 手順書: 公開する(GitHub Pages)

- 目的: https で開ける場所に置く(カメラは https でないと使えない)。
- 入力: 公開先のリポジトリ(新しく作るのは 人が GitHub で行う)。
- 手順:
  1. このフォルダ一式を main に送る(`testdata/` は送らない。`.gitignore` 済み)。相対パスだけで動くので、サブフォルダでもよい。
  2. Pages を有効にする: Settings → Pages → Deploy from a branch → `main` / `(root)`。コマンドなら `gh api -X POST repos/<持ち主>/<リポジトリ>/pages -f "source[branch]=main" -f "source[path]=/"`。
  3. 公開ページを 疑似カメラで確かめる: `BASE_URL=https://<持ち主>.github.io/<リポジトリ>/ node tools/run_app.cjs solo tools/scripts/flows.cjs out/live`。
- 完了条件: 3 の試験が エラー0件。スマホで開き、カメラの許可 → 顔に なりきりが乗る。
- 失敗時: 「この ページでは カメラが つかえません」→ https か確かめる。読み込みで止まる → `vendor/` と `models/` が配られているか確かめる。
- デモの間は `index.html` に `<meta name="robots" content="noindex">` を入れて 検索に のらないようにしてある。正式に出すときに この1行を消す。

## 試験

```
npm i            # playwright を入れる(はじめだけ)
npm run dev      # http://127.0.0.1:8765/ で開く(パソコンのカメラで動く)
npm run test:items   # 12種を 疑似カメラで着せて撮る
npm run test:flows   # 背景オフ・タップ・撮影・まねっこ・写真モードの通し
```

試験には 顔のうつった たて長の動画 `testdata/scenes/<名前>.mjpeg` が要る(同梱していない)。
手持ちの画像から作る例: `ffmpeg -loop 1 -i face.png -t 4 -r 30 -vf "scale=720:1280,format=yuvj420p" -c:v mjpeg -q:v 4 -f mjpeg testdata/scenes/solo.mjpeg`
Chrome の場所を指定するときは `CHROME_PATH` を渡す。URL に `?debug=1` を付けると 速さの表示と試験用の窓口(`window.__nk`)が出る。
